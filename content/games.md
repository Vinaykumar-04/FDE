# Field labs

Every lab contains three decisions. Each correct answer contributes one third of the 100 XP potential. A replay only adds the improvement over the learner's previous best, so retries cannot inflate progress. Each answer includes an explanation.

## Level 0 · Recruit

- **Status Code Match** — Match a customer situation to an HTTP response.
- **Terminal Quest** — Pick safe commands for basic file navigation.
- **JSON Debugger** — Inspect payload shape and data types.

## Level 1 · Builder

- **API Range** — Choose methods, endpoints, and first debugging checks.
- **Data Desk** — Filter, join, and preview data changes.
- **Dockerfile Puzzle** — Select repeatable builds and safe runtime configuration.

## Level 2 · Integrator

- **Retry Storm** — Recover from rate limits and transient failures without amplifying them.
- **Pipeline Builder** — Validate, transform, load, and resume data safely.
- **Webhook Doctor** — Verify signatures and process duplicate deliveries safely.

## Level 3 · AI Engineer

- **RAG Workshop** — Constrain retrieval, handle missing evidence, and cite sources.
- **Tool Calling** — Validate arguments, authorization, and consequential actions.
- **Prompt Fixer** — Improve bounded instructions and check varied examples.
- **Eval Lab** — Detect grounding and quality regressions with repeatable evaluations.

## Level 4 · Field Operator

- **Security Checkpoint** — Apply least privilege, rotate exposed credentials, and enforce tenant boundaries.
- **Incident Commander** — Stabilize service, communicate impact, and verify recovery.
- **Deploy Roulette** — Plan approved offline delivery, migration recovery, and staged rollout.

## Level 5 · FDE Hero

- **Customer Room** — Uncover user workflow and customer impact.
- **Scope Wars** — Prioritize a measurable first outcome and manage dependencies.
- **Interview Gauntlet** — Explain assumptions, reasoning, and personal contribution.
- **Portfolio Review** — Make a project reproducible without exposing customer data.
