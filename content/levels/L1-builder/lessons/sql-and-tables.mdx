## Why it matters for an FDE

Customer data often lives in relational databases. SQL helps you inspect and combine that data without changing it accidentally.

## The idea

A table stores rows of records and columns of fields. SQL statements select, filter, join, or change those records.

> A table is like a labeled spreadsheet; a query is a careful instruction for finding specific rows.

## Worked example

A customer asks for paid orders from yesterday. Filter the orders by status and date, then select only the fields needed for the report.

## Common mistakes

- Running an update or delete before confirming which rows the condition matches.
- Start with a SELECT using the same WHERE condition, review the returned rows, and use a transaction for approved changes.
