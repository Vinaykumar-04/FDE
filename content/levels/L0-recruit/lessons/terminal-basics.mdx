## Why it matters for an FDE
Many developer tools run in a terminal. You can inspect files, run an app, and see useful error messages without hunting through menus.

## The idea
Treat the terminal like a precise conversation with your computer. You type a short instruction; the computer replies with text. The current folder is your location in that conversation.

## Worked example
`pwd` shows where you are. `ls` lists the files there. `cd projects` moves into a folder named `projects`. `cd ..` moves one folder up. Start by looking around before changing anything.

## Common mistakes
- Typing a command in the wrong folder.
- Copying a command without knowing what it changes.
- Confusing the terminal with Python: they are different tools, though a terminal can start Python.
