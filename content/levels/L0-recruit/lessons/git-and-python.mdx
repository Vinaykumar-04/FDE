## Why it matters for an FDE
Git helps you work safely with code and collaborate with a team. Python is a readable programming language often used for scripts and integrations.

## The idea
Think of Git as checkpoints in a journey. If a new change causes trouble, you can inspect earlier checkpoints. In Python, a variable is a labeled box that holds a value for your program to use.

## Worked example
In Python, `customer = "Asha"` stores text in a variable named `customer`. A Git commit can capture that script together with a short message such as “Add customer greeting.”

## Common mistakes
- Saving a commit message that says nothing useful, such as “stuff”.
- Changing many unrelated files in one checkpoint.
- Expecting Git to automatically understand whether code is correct.
