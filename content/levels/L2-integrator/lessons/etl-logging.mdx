## Why it matters for an FDE

Data sync work is easier to trust when each step is visible and failures can be traced.

## The idea

ETL means extract, transform, and load. Logs record useful events and context so a person can understand what a run did.

> ETL is like sorting parcels: collect them, label them in the receiving format, then place them on the right shelf.

## Worked example

Read yesterday’s support tickets, map priority values, load them into a reporting table, and log the run ID and number of accepted or rejected rows.

## Common mistakes

- Logging tokens or personal data, or swallowing errors so a partial load looks successful.
- Log run IDs, counts, durations, and safe error codes; keep sensitive values out of logs.
