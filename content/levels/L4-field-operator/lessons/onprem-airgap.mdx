## Why it matters for an FDE

Some customers run software in their own data center or a network that cannot connect to the public internet.

## The idea

An on-premises deployment runs on customer-managed infrastructure. An air-gapped environment has no direct connection to an external network.

> It is like delivering a sealed kit to a secure site where outside delivery services cannot enter.

## Worked example

The customer needs a release package in an isolated network. Confirm approved transfer, signatures, dependencies, update procedure, and support path.

## Common mistakes

- Assuming the environment can download images, call external services, or receive updates automatically.
- Inventory dependencies and approvals early, then test the exact installation path the customer permits.
